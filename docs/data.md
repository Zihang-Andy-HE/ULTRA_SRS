# Example data

Example TIFF downloads are not yet published. A stable external link and checksum will be added by the maintainer. No tissue images are included in this source distribution.

The metadata JSON files illustrate the evaluated G5 acquisition only: 1024 × 1024 planes, uint16 storage with a 4095 native intensity maximum, XY spacing 0.4143204 µm, Z spacing 1 µm. Never apply these values or its slice-dependent denoising policy to another acquisition without validation. Preserve original source slice IDs. Absolute depth origin and measured spectral band remain unspecified.
